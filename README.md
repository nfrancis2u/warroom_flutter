# Christian Social App (Flutter)

A simple cross-platform social media application aimed at the Christian community.  
Runs on **Android** and **the web** from a single Flutter code-base.

---

## ✨ Features

* Email / password authentication (Firebase Auth).
* Post Bible-inspired thoughts, testimonies, or prayer requests.
* Real-time feed powered by Cloud Firestore.
* Like posts, add comments, and view how others interact.
* Responsive design – one codebase for both mobile and web.

> This is an MVP intended as a starting point. Feel free to customise UI, add push notifications, photo uploads, etc.

---

## 🛠️ Prerequisites

1. **Flutter SDK** (3.10 or newer) – [installation guide](https://docs.flutter.dev/get-started/install).  
2. **Firebase account** – create a new project at <https://console.firebase.google.com>.

---

## 🔥 Firebase setup (one-time)

1. Inside the Firebase console, click **Add app** ➜ **Android**.
   * Android package name: `com.example.christian_social_app` (or your own).
   * Download `google-services.json` and place it in `android/app/`.
2. Add a **Web** app in the same project. Copy the config snippet (we will generate it automatically later).
3. Install FlutterFire CLI:

```bash
flutter pub global activate flutterfire_cli
```

4. From the project root, run:

```bash
flutterfire configure
```

   * Select the Firebase project you just created.
   * Enable **Android** and **Web** platforms.
   * This generates `lib/firebase_options.dart` automatically.

> The repo already contains a placeholder for `firebase_options.dart` so the project compiles before you run the CLI. **Be sure to overwrite it** with the generated file for production builds.

5. (Android only)  Ensure the Android project is using Kotlin 1.8+ / Gradle 8+, as prompted by the FlutterFire CLI.

## ▶️ Running the application

### Web (for fast development)

```bash
flutter run -d chrome
```

Or, if you prefer a hot-reloading dev server:

```bash
flutter run -d chrome --web-renderer canvaskit
```

### Android

```bash
flutter run -d <android-device-id>
```

Build an APK/AAB:

```bash
flutter build apk   # or: flutter build appbundle
```
